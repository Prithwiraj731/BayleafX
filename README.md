## ✦ Overview

**BayleafX** is an independent digital atelier and software engineering platform fusing architectural precision with luxury brand elevation and cybernetic aesthetics. Designed with custom dark brutalism, high-contrast typography, and fluid kinetic interactions.

---

## ⚡ Core Features

- **Cybernetic Mobile & Desktop Hero**: Custom cybernetic background art, interactive swipe-right telemetry button, and fluid entrance choreographies.
- **Glassmorphic Design System**: Custom tokens (`#0B0B0B` obsidian black, `#F5F2ED` bone white, and `#8B0D1A` crimson red accents).
- **Responsive Architecture**: Pixel-perfect viewports across mobile, tablet, and ultra-wide displays.
- **High-Performance Motion**: Powered by Framer Motion with custom spring physics and cubic-bezier transition curves.
- **SEO & Structured Metadata**: Complete OpenGraph, Twitter card tags, viewport management, and semantic HTML5 hierarchy.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.18+ or later
- npm, pnpm, or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Prithwiraj731/BayleafX.git
   cd BayleafX
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.
